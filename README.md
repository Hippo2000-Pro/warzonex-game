# War Action Game

Projet de base pour un jeu d'action et de guerre en vue de combat.

## Structure

- src/game.js : logique principale du jeu, mission, vagues, rendu
- src/entities : joueur et ennemis
- src/world : génération de cartes, obstacles, extraction
- src/systems : armes et règles de combat
- style.css : interface et HUD
- docs : spécifications et fiches de design

## Objectif

Créer une base jouable et extensible pour un jeu de guerre tactique à la première personne / à la troisième personne, avec ennemis, équipe, mission, recharge, loot, progression et monde aléatoire.

## Étapes couvertes

1. Base du projet et structure du dépôt
2. Prototype jouable de combat
3. Armes, ennemis, vagues et random map
4. Mission de nettoyage + extraction
5. Personnages jouables et IA d'équipe
6. Loot, soins et amélioration rapide de l'équipement
7. Préparation des phases suivantes : alliés, véhicules, météo, progression
